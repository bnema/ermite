# Vendored web assets

`static/` is embedded in the binary and served under `/-/static/` with
content-hashed names. Nothing is fetched at runtime.

| File | What | Source | SHA-256 |
| --- | --- | --- | --- |
| `static/js/htmx.min.js` | htmx 4.0.0 (BSD Zero Clause, `static/js/htmx-LICENSE`) | `mockups/assets/htmx/htmx.min.js` of the design | `e484d9171a9db30a39c8f16e3d709d4137f3211c659f8e6125816635033d593f` |
| `static/js/hx-live.min.js` | htmx 4 `hx-live` extension | `mockups/assets/htmx/ext/hx-live.min.js` | `adf9b90949d57baf20dc2eaf1d1fd46c81347ac82c090a5e2912ce6b37726734` |
| `static/js/hx-sse.min.js` | htmx 4 `hx-sse` extension | `mockups/assets/htmx/ext/hx-sse.min.js` | `8a834680c4000a9034d79228872372a92e140c810a075cb6d4a76690dfc13085` |
| `static/js/ermite.js` | key sequences to `k-*` events | `mockups/d/js/ermite.js` | |
| `static/css/56-chroma.css` | syntax classes of the code view, mapped to the `--syn-*` tokens (no colour of its own) | generated by `go run scripts/chroma-css.go` from chroma's token classes | |
| `static/css/*.css` | native CSS of design D, served as one stylesheet in name order | `mockups/d/css/` (+ `70-footer.css`, the AGPL §13 source link) | |

The three htmx files are the exact files the approved mockup was built with.
To upgrade, replace the file, update the checksum here, and run the web tests
(`go test ./cmd/ermite -run TestWeb`).

`*_templ.go` files are generated by `go tool templ generate` (templ is pinned
in `go.mod`) and committed; `scripts/templ-drift.sh` fails when they are stale.
